# 접근성 점검 결과 (KWCAG 기본 항목)

> 2026-11-13 점검 · 실제 BE(덤프 복원 DB) + 목업 · 1440×900 · Edge headless
> 점검 방법: Lighthouse 접근성 검사의 주요 항목(이름 없는 버튼·링크·입력, 대체 텍스트, 색 대비, 제목 순서, lang·title, 표 머리글, 중복 id, tabindex)을 브라우저 안에서 직접 검사 + 키보드(Tab·Enter·Space·방향키·Esc)만으로 전체 흐름.
> Lighthouse 점수는 이 환경에서 Lighthouse를 내려받아 실행하는 것이 막혀 측정하지 못했다 — Edge 개발자 도구 → Lighthouse → 접근성으로 한 번 확인한다.

점검 화면: 랜딩 `/`, 입력 `/diagnose`, STEP 02 `/result/analysis`, STEP 03 `/result/summary`, STEP 04 `/result/share`, 404, 진단서 `/result/report`

## 1. 자동 검사 항목

| 항목 | 점검 전 | 조치 | 점검 후 |
|---|---|---|---|
| `html lang="ko"`, 페이지 제목 | 모든 화면 있음 | — | 통과 |
| 본문 바로가기 | 결과 화면(STEP 02~04)에만 | 공통 `SkipLink` — 랜딩·입력·404·진단서에도 추가 (`<main id tabIndex=-1>`) | 7개 화면 모두 첫 Tab |
| 제목 순서 (h1→h2→h3) | STEP 03·04에서 h1 다음 h3 (상권 판정·서울 평균 비교·AI 해석·상담 링크 묶음) | `SubTitle`에 `as="h2"` 선택 (모양 그대로) | 건너뜀 없음 |
| 이름 없는 버튼·링크·입력 | STEP 02 지도: 카카오 SDK 로고 링크, 진단 위치 마커 `<area alt="">` | 로고 링크 `aria-label="카카오맵 (새 창)"`, area `alt`=title("진단 위치") | 0개 |
| 이미지 대체 텍스트, 중복 id, tabindex>0, 표 `th scope` | 문제 없음 | — | 통과 |
| 색 대비 4.5:1 | 흰 글자 + 파란 바탕(`blue-500` #3376FD) **4.08:1** — 주요 버튼(진단 시작하기·이 자리 진단하기·AI 해석 보기·PDF로 저장·처음으로), "서울시 공식" 배지, 번호 원 / 연도별 차트 범례 글자 개업 4.08·폐업 3.93 | `blue-600` 토큰(#2E6CE8, **4.74:1**) 추가 후 흰 글자 바탕에만 적용 (마커·막대·테두리는 그대로) / 범례 글자는 진한 회색, 색은 동그라미로 | 0건 (로고 ":ON"은 로고라 예외) |
| 화면 읽기 알림(aria-live) | 로딩·오류·이미지 저장은 있음, **AI 결과 도착은 알림 없음** | 결과 도착 시 `role="status"` "AI 해석을 불러왔어요" (실패는 기존 `role="alert"`) | 통과 |

## 2. 키보드만으로 전체 흐름

| 단계 | 결과 | 조치 |
|---|---|---|
| 입력: 본문 바로가기 → 로고 → 주소 입력 → 카페(Space) → 진단하기(Enter) → 후보 목록 첫 항목에 자동 포커스 → Enter | 통과 | — |
| STEP 02: 첫 Tab 본문 바로가기, 반경 라디오(방향키) → 조회 → 표 "지도에서 보기"(Enter) → 지도 정보창 열림, 더보기, 시점 빠른 선택(1년 전) | 통과 | — |
| 지도 안 | 갇힘 없음 (카카오 SDK의 진단 위치·로고·확대/축소 4곳만 지나감). **점포 마커는 키보드로 고를 수 없음**, 정보창 닫기 버튼이 확대/축소 뒤에 있어 찾기 어려움 | 지도에 대체 안내 연결(`aria-describedby`): "키보드·화면 읽기 프로그램으로는 아래 점포 상세 조회 표에서 같은 점포를 고를 수 있고, 고른 점포는 지도 정보창에 열려요. 정보창은 Esc 키로 닫아요" + **Esc로 정보창 닫기** |
| STEP 03: AI 해석 보기(Enter) | **버튼이 사라지며 포커스가 본문 처음(body)으로 튐** | 결과 영역으로 포커스 이동 → 다음 Tab이 "다시 시도" |
| STEP 04: 요약 이미지 저장(Enter) → "요약 이미지를 저장했어요" 알림, 상담 링크·PDF 진단서 버튼 도달 | 통과 | — |
| 포커스 표시 | 모든 요소 보임 (주소 입력은 바깥 상자 `focus-within` 테두리) | — |
| 동작 줄이기 | 기존 `prefers-reduced-motion` 대응 유지 (모션 유틸·차트·스켈레톤) | — |

## 3. 그대로 둔 것 (이유)

| 항목 | 이유 |
|---|---|
| 지도 점포 마커를 키보드로 하나씩 고르기 | 반경 1,000m는 마커 1,000개 이상이라 Tab 정지점으로 만들면 오히려 이동이 어려움. 같은 기능을 표(키보드 가능)로 제공하고 지도에 안내를 연결함 |
| 지도 마커 색만으로 상태 구분, 묶음 숫자 배지(흰 글자 + 상태 색) 대비 | 지도 그래픽은 색으로 구분하되 범례에 글자, 마커 title·정보창·표에 상태 글자가 함께 있음. 마커 색을 바꾸면 범례·디자인 색 체계가 바뀌어 유지 |
| 로고 ":ON"(blue-500, 4.08:1) | 로고·브랜드 글자는 대비 기준 예외 |
| Lighthouse 점수 | 이 환경에서 Lighthouse 실행이 허용되지 않음 — 위 자체 검사로 같은 항목을 확인했고, 점수는 개발자 도구에서 따로 확인 |
