# 검색 위치의 매출·행정동 생활인구 참고자료

BE #190 / FE #81. 기존 분석·요약·인쇄 진단서의 세 카드에 `GET /api/v2/location-reference`를 연결한다. 화면 구성은 유지하고 각 자료의 실제 날짜·지역·인구 범위를 표시한다.

- 입력은 lat/lng/radius/category/sub_category/as_of/time_mode 7개다. 가맹·브랜드·면적 조건은 보내지 않는다. 업종은 매출 업종 선택에만 사용하며 생활인구를 업종으로 거르지 않는다.
- 기본 `latest_reference`는 적재된 실제 최신 참고자료를 선택한다. 분석일2023-11-30과 매출 자료분기2025년4분기, 인구 관측일2026-10-31은 별도로 표시한다. `analysis_period`는 해당 분석월만 허용하고 자료 없음을 다른 월 값으로 채우지 않는다.
- 매출은 원자료 원화 금액 문자열이다. JS Number 변환·월/분기 환산·상권 합산을 하지 않는다. 자료분기 표시가 집계 기간 확정을 뜻하지 않는다.
- 생활인구는 공식 행정동 내국인(local) 자료의24시간 시간당 평균이다. 외국인을 포함한 전체 인구·일일 순방문객·반경 안 인구라고 표시하지 않는다.
- 주간06~17시, 야간00~05/18~23시는 같은 행정동·관측일·자료 출처로만 비교한다. 비공개/누락은0으로 채우지 않는다. 야간0이면 비율 없음, 반올림0과 실제0도 구분한다.
- 실제 검색 위치 포함동이 우선이다. 포함동에 자료가 없으면 그 행을 남기고 실제 반경 교차동을 ‘대체값 아님’으로 표시한다. 복수 포함동은 각각 표시하며 최근접/유사 구역을 쓰지 않는다.
- 기존 AI/Risk와250m격자 공개 부분자료는 별도 계약이다. 기존 격자 카드는 접힌 세부 항목으로 유지하고 새 참고값은 기존AI에 입력하지 않는다.
- 요청 취소/조건별 캐시 분리/로딩·오류는 독립 처리한다. 보고서 인쇄 버튼은 새 참고 조회까지 기다린다. 서버 미제공·오류·실제 결측에는 숫자를 만들지 않는다.

검증: Vitest193개·배포프로필4개, 분석/요약/보고서 실제API문자열 대조,360/390px 가로넘침 없음, 실제 Chromium PDF 생성. 배포 후 실제 커밋/공개 확인 결과는 연결PR 및 BE 설계 실행기록을 따른다.
