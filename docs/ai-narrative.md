# AI 해석 문단과 정보 팝오버

2026-11-14 사용자 요청에 따라 FE·BE를 함께 변경한다. BE #130의 설계가 집계 기준이며 번호형 네 구역과 반복 근거 칩을 화면/진단서에서 제거한다. 디자인 토큰·색상과 다른 분석 기능은 유지한다.

`POST /api/risk/interpret`의 query-only·선택 history 요청은 유지한다. 응답의 검증된 `body`를 빈 줄 단위 문단으로 표시하고, `paragraphs`·`used_indicator_ids`·`evidence`와 기존 배열은 내부 근거로 보존한다. AI는 서버가 실제 집계로 만든 문단 후보를 선택한다. 주소·수치·프롬프트·키를 FE에서 모델에 직접 전송하지 않는다. 구버전 서버가 body를 제공하지 않으면 해석 오류 안내를 보여주며 FE가 문장을 만들어 채우지 않는다.

제목 옆 ⓘ는 비모달 dialog다. 클릭 토글, 외부 클릭, Esc, 포커스 이탈로 닫힌다. 열 때 닫기 버튼으로, Esc/닫기 때 트리거로 포커스를 이동한다. `aria-expanded/controls/haspopup/labelledby`를 제공한다. 확보 자료·미확보 자료와 요청별 missing_data, 사용자 요청의 여덟 가지 해석 한계는 이 안에서 확인한다. 원천 기준일과 수집일을 혼동하지 않는다.

주소·업종·반경·실제 적용 T·시설 규모·가맹·면적/가맹 정보 없음 포함 여부·원천 기준일을 본문 위에 표시한다. 캐시 키는 조회 조건뿐 아니라 주소·건물 키·층호·본문 버전을 포함하고 진단서에서도 같은 키를 쓴다. 조건이 바뀌면 이전 결과를 숨기고 진행 중 요청을 취소한다. 클릭 전 AI POST와 자동 재시도는 없다. 503/검증 실패에도 지표 카드는 유지한다.

기간 표시는 BE가 확정한 값을 읽는다. 최근12개월 `(L,T]`의 시작일은 L 다음 날이다. 참고 폐업률의 분모는 T 영업 기록+최근 폐업 기록이며 시점 점포 수와 다르다. 연도별 YTD와 최근12개월, 경과 기간과 폐업 기간, 서로 다른 주년 관측 집단을 합치지 않는다. `%p`는 BE가 계산하므로 FE에서 재계산하지 않는다.

모바일에서 기존 사이드바 대신 같은 단계 링크를 표시하고, 조건/참고지표/안내/문단과 팝오버가 화면 안에 들어가도록 반응형 배치를 보완했다. 데스크톱 배치는 유지한다. 실제 DB+Gemini 응답을 표시한 Chrome1440·390·360px 검사에서4문단·키보드 포커스/닫기·외부 클릭·가로 넘침 없음·조건 변경 후 결과 제거·자동 POST 없음·모의503 지표 보존을 확인했다. 진단서도 기존 배열 나열 대신 같은 body를 사용한다.
