# 공개 부분자료 AI 호환 연결 (#76 / BE #184)

2026-11-16 사용자의 다음 단계 진행 요청으로 검수된 BE #182 설계를 실제 구현한다. 요청 형식/수동 요청/취소·조건 캐시/4문단 plain text는 유지한다.

- evidence.population_reference는 optional이다. 구 BE promptv1·필드없음은 기존 문구로, 새 promptv2·정합한 자료는 부분자료 상태/관측일과 함께 표시한다.
- interpretationMatches는 두 버전만 허용한다. 새 버전의 근거 부재·승인true·다른 기준일/관측월·원천순서/상태 불일치는 거절하며 AI만 실패하고 핵심 지표는 남긴다.
- AiPopulationInfo는 정보 팝오버·보고서에 AI POST의 관측일과 원천별 부분/결측 상태를 보여 준다. GET 카드와 다른 날짜이면 둘을 유지한다. 인구를 점포 필터로 거르거나 전체 인구로 표시하지 않는다.
- 인허가 출처 줄과 별도로 partial이 있으면 서울시 생활인구250m 격자 공개자료(R4)를 표시한다. 근거명은 상태 중립적이며 지표 카드로 이동하지 않는다.
- 전체 생활인구/매출 미확정 안내는 유지하되 별도 부분 비교와 모순되지 않게 분기한다. 외국인 값을 내국인으로 대체하지 않는다.

단위188개/profile4개·lint 및 실제 로컬 복제DB/모의 ID선택 공급자 브라우저에서 새 본문/정보창·390/360·보고서/PDF·유효 no_data200·AI전송실패의 핵심지표 보존을 확인했다. 실제 LLM 호출/운영 배포와는 구분한다. 정확한 CI·실제 공개 검증은 이슈/PR 실행 기록을 따른다.

배포는 FE feature→develop PR, develop→main release/Vercel을 먼저 완료하고 기존BE의 필드 없는 응답 표시를 확인한 뒤 BE를 배포한다. 키/.env·호스팅 설정·사용자 폴더는 바꾸지 않는다. 복구는 이전BE를 먼저 반영하고 필요할 때 FE도 이전 배포로 돌린다. 전체 인구 공식 근거는 BE #115/#78에서 계속 추적한다.
