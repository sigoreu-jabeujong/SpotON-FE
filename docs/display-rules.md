# 화면 표시 원칙

> 마지막 갱신: 2026-11-10
> 기준: 08 분석 로직 정의서 5장(화면 표시 규칙), 06 API 명세서 v1.1 2-3·2-4, 07 데이터 활용 명세서 2.5·8장, BE 작업계획서 7절
> 대원칙: **FE는 지표를 계산하지 않는다.** 서버가 준 값을 그대로 보여준다 (날짜·숫자 형식 변환만 예외).

## 1. 공식 지표와 참고지표 분리

- **영역을 눈에 띄게 나누고** 라벨을 붙인다: `type: official` → "서울시 공식", `type: reference` → "Spot:ON 참고지표".
- **참고지표에 등급 색을 쓰지 않는다** (빨강=위험, 초록=안전 같은 신호등 색, "정상·주의·위험" 표현 금지).
- **공식 폐업률(분기·정수 %)과 참고 폐업률(12개월·소수 첫째 자리 %)은 같은 카드에 섞지 않는다.** 기간과 공간(상권 vs 반경)이 달라 직접 비교할 수 없다.
- 공식 창업위험도는 수치·등급을 만들지 않고 서울시 상권분석서비스 **링크로 안내**한다. 자체 점수로 대신하지 않는다.
- 성공·실패 확률, 종합 위험점수·위험등급, 추천/비추천 판정을 화면 어디에도 만들지 않는다.

## 2. 지표마다 붙일 정보

모든 수치 아래(또는 옆)에 작게 표시한다.

| 정보 | 가져올 곳 | 예시 |
|---|---|---|
| 출처 | `source` (R번호) → [출처 번호 표](#7-출처-번호-표) | 출처: 행안부 일반·휴게음식점 인허가 (R5·R6) |
| 기준일 | `meta.as_of` 또는 지표 `period` | 기준일 2026.10.31 / 2026년 2분기 |
| 공간 단위 | `space` | 반경 500m / 상권(○○역) / 250m 격자 |
| 분모(표본) | `denominator` | 표본 46곳 |
| 상태 라벨 | `status` | 확인된 사실 · 통계적 추정 · 자료 없음 · 판단 보류 · 정보 없음 · 상세 위치 미확인 |

- 상태 라벨 6종은 **색과 아이콘**으로 구분한다 (색만으로 구분하지 않기 — 접근성).
- **집계 단위가 다른 수치는 카드를 나눈다**: 점포 수(반경) / 매출(상권) / 생활인구(격자). 카드 제목에 단위명을 넣는다.
- 매출·생활인구는 "추정치"라고 쓰고, 점포의 실매출·실고객으로 표현하지 않는다.

## 3. 숫자·날짜 형식

| 대상 | 규칙 | 예시 |
|---|---|---|
| 날짜 | `YYYY.MM.DD` | 2026.11.08 |
| 영업 기간 | `operating_months` → "n년 m개월" | 77 → 6년 5개월 |
| 비율 | 소수 첫째 자리 % (서버 값 그대로) | 17.4% |
| 공식 폐업률 | 공표값 정수 % | 4% |
| 점포 수 | 정수 + "곳" | 38곳 |
| `null` 값 | **0으로 표시하지 않는다.** `status`와 `reason`(사유)을 보여준다 | 판단 보류 — 신규 점포 5건 미만 |

## 4. 데이터 기준일 표시

화면(결과 화면 상단 또는 하단)에 아래 형식으로 함께 표시한다.

```text
데이터 기준일 YYYY.MM.DD (수집 YYYY.MM.DD)
```

- 데이터 기준일 = `meta.data_updated_at`, 수집일 = `meta.collected_at`.

## 5. AI 해석

- **"AI 해석" 라벨**로 계산 결과와 확실히 구분한다.
- 사용자가 **"AI 해석 보기" 버튼을 눌렀을 때만** 요청한다 (페이지 열 때 자동 요청 금지 — Gemini 이용 조건 대응).
- 순서: (1) 공식·계산값 요약 → (2) 유리 요인 / (3) 불리 요인 **나란히** → (4) 부족한 자료 → (5) 계약 전 현장 확인사항.
- 문장마다 **근거 지표 칩**을 단다 (`indicator_ids[]` → 지표 이름). 예: [동종업체 수] [참고 폐업률]
- 실패해도(`AI_UNAVAILABLE`, `AI_VERIFY_FAILED`, 타임아웃) **지표는 그대로** 두고 이 문구를 보여준다: **"AI 해석을 불러오지 못했어요"** (`MESSAGES.ai.unavailable`)
- AI 해석은 참고용이며 전문 조언이 아니라는 안내와 공공 상담(F-10) 연결을 함께 둔다.
