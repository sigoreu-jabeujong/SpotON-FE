# 시연 대본 (3분)

> 마지막 갱신: 2026-11-11
> 기준: 데스크톱 1440×900, 개발 서버 `npx vite --port 5180`. BE가 준비되지 않았으면 목업으로 시연한다 ([아래 3장](#3-목업으로-시연할-때)).
> ⚠️ **실제 시연 주소: 팀장 확인 대기** (2~3곳 요청함). 정해지면 1장의 주소를 바꾼다. 아래 숫자는 모두 목업(시연용 가상 값)이다.

## 2. 꼭 보여줄 차별점 4가지

1. **주소별 과거 점포 이력** — 같은 건물의 인허가 이력, 위치 일치(같은 자리 / 같은 건물 다른 위치 / 상세 위치 미확인)
2. **과거 시점 조회** — 그 시점 동일 업종 N곳 → 지금도 운영 중 A곳 · 이후 폐업 B곳 (서버 값 그대로)
3. **공식/참고지표 구분** — "서울시 공식"과 "Spot:ON 참고지표" 영역 분리, 모든 수치에 출처·기준일·공간 단위·상태 라벨, 자체 점수·등급 없음
4. **근거 기반 AI 해석** — 클릭할 때만 생성, 근거 지표 칩, 실패해도 지표는 그대로

## 3. 목업으로 시연할 때

`.env` (값은 팀 개인톡으로 받은 것 사용, 저장소에 올리지 않는다):

```text
VITE_USE_MOCK=true
VITE_KAKAO_JS_KEY=(카카오맵 JavaScript 키)
```

`.env`를 바꾸면 개발 서버를 다시 켠다 → `npx vite --port 5180` → <http://localhost:5180>

목업 테스트 규칙 요약 (시연 중 일부러 쓰지 않도록 주의):

| 입력 | 결과 |
|---|---|
| 주소에 `없는` / 서울 외 지역명(`경기도`, `세종시` 등) / `여러` | 주소 없음(404) / 서울 외(422) / 후보 목록 |
| 반경 300m | 표본 부족(판단 보류), AI 해석 검증 실패 |
| 반경 1,000m | AI 해석 실패(503) |
| 기준 시점 2025-01 이전 / 2021-01 이전 | 추정매출 없음 / 생활인구도 없음 |
| 음식점 | 공식 창업위험도 링크 안내 형식, 서울 평균 있음 |
| 선택 가능 기간 | 2010-01 ~ 2026-11 |

**BE가 일부만 준비됐을 때**: 목업은 켜 둔 채 준비된 API만 실제 서버로 부를 수 있다 → [api-contract.md "BE 단계 연결"](api-contract.md#be-단계-연결-api별-목업-스위치) (`VITE_REAL_API_PATHS`).

## 4. 실패 대비

| 상황 | 원인 확인 | 대처 |
|---|---|---|
| 지도 자리에 "지도를 불러오지 못했어요" | `.env`에 `VITE_KAKAO_JS_KEY`가 있는지, 주소가 **`localhost:5180`** 인지 (카카오 콘솔에 등록된 도메인만 지도가 뜸) | 포트 5180으로 다시 실행. 그래도 안 되면 "지도 아래 표에 같은 점포가 그대로 있어요"라고 말하고 표로 진행 |
| AI 해석 실패 ("AI 해석을 불러오지 못했어요") | 목업에서 반경 300m·1,000m로 바꿨는지, 실제 서버면 LLM 한도 | "AI가 실패해도 계산된 지표는 그대로예요. AI는 보조 설명일 뿐이에요"라고 설명하고 [다시 시도] 또는 반경 500m로 돌린다 |
| 실제 서버 연결 오류 ("서버에 연결할 수 없어요") | BE 서버가 켜져 있는지, `VITE_API_BASE_URL` | `VITE_REAL_API_PATHS`를 비우고 개발 서버를 다시 켜면 전부 목업으로 시연 가능 |
| 한 섹션만 "이 정보를 표시하지 못했어요" | 응답 형식이 예상과 다름 | 다른 섹션은 그대로이니 그 섹션은 건너뛴다. [다시 시도] 한 번 |
