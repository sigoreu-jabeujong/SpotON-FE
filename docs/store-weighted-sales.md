# 점포 수 기준 매출 추정 분포

2026-11-17 사용자 최신 요청으로 기존 총점포 수 공통분모 기여 그래프를 교체한다. BE #212의 `store_weighted_median_v1`/`store_weighted_histogram_v1`/`store_weighted_distribution`을 사용한다. 개별 점포 매출 원자료가 없으므로 상권별 평균 sᵢ/nᵢ에 nᵢ개 가중치를 적용한 추정 모델이다. 실제673개 점포의 독립 관측값을 생성/추론했다고 표현하지 않는다. 기준 수는 위치별 원자료 점포 수 합으로 동적 계산된다.

대표는 서버 가중 중앙값이고, 막대 높이 합은 총점포 수 가중치 합 N이다. 가로축은 점포당 추정 매출 구간, 세로축은 점포 수 가중치. 가중평균·상권 평균 간 분산은 비교/상세 정보다. 각 구간 선택·좌우/Home/End, 모바일/인쇄, 실제0·같은 값·빈 구간·자료 없음 처리를 확인한다. FE는 중앙값/분산을 재계산하지 않으며 기존 생활인구/출처 배치를 유지한다. 실제 Claude 검토와 통계 규칙·배포 기록은 BE의 `docs/designs/feat212-store-weighted-sales.md` 및 연결PR을 따른다.
